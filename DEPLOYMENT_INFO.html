Voucher Management System

Deployment Instructions

This application consists of two parts:

  1. Frontend: Static HTML/CSS/JS files (in the out directory)
  2. Backend: Node.js API server (in the mysql-backend directory)

Step 1: Deploy Backend Server

Upload the mysql-backend folder to your hosting provider and set it up as a Node.js application:

  • Create a MySQL database
  • Update mysql-backend/.env with your database credentials
  • Run npm install in the mysql-backend directory
  • Start the server with node index.js

Step 2: Deploy Frontend Files

Upload all files from the out directory to your web server's document root (e.g., public_html)

Step 3: Configure API Connection

Update the frontend to connect to your backend server:

  • If your hosting supports environment variables: set NEXT_PUBLIC_API_BASE_URL to your backend URL
  • Otherwise, update the API URL in the built frontend files to point to your backend server

Important Files/Folders:

  • out/ - Frontend static files to upload to public_html
  • mysql-backend/ - Backend API server
  • DEPLOYMENT_GUIDE.md - Detailed deployment instructions
  • mysql-backend/setup-database.sql - SQL script to create database tables

For detailed instructions, please refer to the DEPLOYMENT_GUIDE.md file.
